Privacy Policy - Tallow and Shadows Uploader

Last updated: 1 October 2026

"Tallow and Shadows Uploader" is a private desktop tool used only by the owner of the YouTube channel Tallow & Shadows to manage that channel. It is not offered to the public.

What the tool accesses

With the owner's permission, the tool uses the YouTube Data API to upload the channel's own videos, set thumbnails, add subtitles, manage playlists, post the channel's own comments and read the channel's own video statistics.

What is stored

The OAuth access token is stored only on the owner's own computer. No data is sold, shared with third parties or sent to any server other than Google's YouTube API.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: through the channel youtube.com/@TallowAndShadows.
